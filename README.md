# Predicting Minimum Proficiency Risk in African Primary Education Using PASEC Survey Data

Author: Gentille Uwera

## Problem Statement

SDG 4, Target 4.1 measures whether children actually learn, through Indicator 4.1.1: the share of children reaching a minimum proficiency level in reading and mathematics. In Francophone Sub-Saharan Africa this is measured by PASEC, a regional assessment coordinated by CONFEMEN across 14 countries.

Knowing which Grade 6 students are below minimum proficiency requires a full learning assessment, which most education systems can only afford periodically and at national sample level. PASEC already collects background information on every tested student (household assets, parental literacy, grade repetition, age, teacher training, class size, school location, home language).

The objective is to test whether that background information alone can flag a Grade 6 student as likely below the PASEC minimum proficiency level in mathematics, without a new test. The intended output is a low-cost, interpretable decision-support prototype, not a classroom device.

## Dataset Overview

| Item | Value |
|---|---|
| Source | PASEC2019 international database, CONFEMEN data portal: https://pasec.confemen.org/en/data-portal |
| File | `PASEC2019_GRADE6_INT.dta` (Stata), inside `PASEC2019_INT_STATA.zip` |
| Documentation | PASEC2019 data manual (CONFEMEN); AFLEARN PASEC Analysis Guide: https://datafirst-aflearn.github.io/pasec-guide/ |
| Sample size (N) | 62,934 Grade 6 students in 3,298 schools, 14 countries |
| Raw columns (P) | 749 (identifiers, test items, plausible values, student, teacher and principal questionnaires, derived indices, survey weights) |
| Features used | 10 background columns. Test items (f1 to f98, m1 to m84), plausible values and survey weights are excluded to prevent target leakage. |
| Target (Y) | `below_min_maths`: 1 if a student is below the PASEC minimum proficiency level in mathematics, 0 otherwise |

**How Y is built.** PASEC reports mathematics achievement as five plausible values per student (MATHS_PV1 to MATHS_PV5). The boundary of the PASEC minimum proficiency level for end-of-primary mathematics is 521.46 (PASEC2019 manual, Table 5.17). A student is labelled 1 when at least 3 of the 5 plausible values are at or below 521.46. Result: 39,685 students labelled 1 (63.1%) and 23,249 labelled 0 (36.9%). Weighted by the final student weight `rwgt0`, the population share below the minimum is 69.1%.

**Schools.** `ID_ECOLE` identifies a school within a country (manual, Table 2.2), so the same code repeats across countries. A school is identified by country plus `ID_ECOLE` (3,298 schools).

## Pipeline Summary

1. **Cleaning.** PASEC missing-value codes (Invalid, Missing, Not applicable and others) are converted to `NaN` per variable, from the codebook.
2. **Split.** 80/20 train/test with `StratifiedGroupKFold`: schools never appear on both sides, and strata (country x label) keep the label rate and country mix equal. 50,347 training and 12,587 test students.
3. **Preprocessing** (`src/pipeline_builder.py`), fitted on the training set only:
   - capping of extreme values (logistic regression only): mean +/- 3 SD for the wealth index, 1.5 x IQR for age and class size;
   - imputation with the mean, median or mode of the student's own country, plus a 0/1 flag for every filled value;
   - log(1 + x) and standardization for logistic regression, original values for gradient boosting;
   - ordinal encoding of ordered answers; one-hot encoding of country (CatBoost keeps country as one categorical column).
4. **Checks.** Cross-validation refits the whole pipeline inside each school-grouped fold, with the loss and metrics weighted by `rwgt0`, for an elastic-net logistic regression, XGBoost and CatBoost. Further checks: two imputation alternatives, the share of label variance between schools (random-intercept model), borderline students (plausible values on both sides of the cutoff) scored separately, and a leave-one-country-out test of country representations.

Output: 32 model columns, 0 missing cells, 0 students dropped.

## Getting the Data

The PASEC files are not stored in this repository. The Grade 6 file is 373 MB uncompressed, above GitHub's 100 MB file limit, and CONFEMEN distributes the data through its portal.

1. Download the PASEC2019 international database (Stata format) from https://pasec.confemen.org/en/data-portal
2. Save `PASEC2019_INT_STATA.zip` unchanged in `data/raw/`.

The zip contains `PASEC2019_GRADE6_INT.dta` (used here) and `PASEC2019_GRADE2_INT.dta` (not used). The code reads the Grade 6 file directly from the zip, so the original is never modified.

SHA-256 of the `PASEC2019_GRADE6_INT.dta` used in this project:
`34bea29630ddc5c6d5723f434abf8f1412a9d16c92c7bd7faa251cfef56453b9`

`data/external/country_indicators.csv` holds government expenditure on education (% of GDP) for the 14 countries, from the World Bank World Development Indicators (SE.XPD.TOTL.GD.ZS), 2019 values (2017 for DR Congo, the latest available).

## Running the Pipeline

**Google Colab**

1. Upload `PASEC2019_INT_STATA.zip` to Google Drive at `MyDrive/PASEC2019/` (or change `DRIVE_ZIP` in the first code cell).
2. Open the notebook in Colab: https://colab.research.google.com/github/GentilleUwera/pasec-minimum-proficiency-risk/blob/main/notebooks/pipeline_execution.ipynb
3. Run all cells. The notebook clones this repository, mounts Drive, copies the zip into `data/raw/`, and installs the pinned packages.

**Locally**

With the environment above activated and the zip in `data/raw/`, open `notebooks/pipeline_execution.ipynb` in Jupyter and run all cells.

The notebook writes the figures to `figures/` and the processed train and test matrices to `data/processed/`.
